# YONO GAMES 2027

Static website made with HTML and CSS.

## Files
- `index.html` — the website
- `assets/` — the five original game logo images supplied in the chat

## Publish with GitHub Pages
1. Create a new GitHub repository named `yono-games-2027`.
2. Upload `index.html` and the complete `assets` folder (keep the folder name `assets`).
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then press **Save**.
6. Wait for GitHub Pages to publish the site. The public URL will appear on the Pages settings screen.

The Download buttons open the third-party links supplied by the site owner in a new browser tab. The website does not host or install APK files.
